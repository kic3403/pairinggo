## 1. 백경증류소 사장님께 (보낼 글)

안녕하세요, 페어링GO입니다. 백경증류소가 파트너 양조장으로 승인됐습니다. 지금 홈 "페어링GO 파트너" 줄과 매장 화면(https://pairinggo.kr/places/306594326?n=백경증류소)에 올라가 있고, 백경15·세종소주·백경53 일곱 종의 술 화면에 "파트너 양조장" 도장이 붙었습니다.

파트너 앱(https://pairinggo-partner.vercel.app)에서 아래 네 가지만 채워 주시면 손님 화면이 바로 달라집니다. 순서대로 10~20분이면 됩니다.

**① 양조장 정보 탭 — 대표 사진·한 줄 소개** (5분)
- 대표 사진 1~10장(양조장 외관·술병·시음 공간). 첫 장이 홈 파트너 줄 동그라미와 매장 화면 맨 위에 쓰입니다. 지금은 사진이 없어 글자로만 나옵니다.
- 한 줄 소개(예: "세종 장군면에서 쌀로 빚고 두 번 내린 증류주"). 이달의 파트너 카드 문구로도 쓰입니다.
- "우리 양조장"은 운영자가 **백경증류소**로 연결해 두었습니다(매장 화면에 술 7종이 자동으로 뜹니다).

**② 판매 탭 — 판매하는 술** (5분)
- "우리 술 7종 불러오기"를 누르면 카탈로그의 술이 표에 한 번에 담깁니다. 용량·도수·가격·설명을 적고, 줄마다 [+ 사진]으로 술 사진을 올려 주세요.
- 올린 술 사진은 카탈로그에 공식 사진이 없는 술의 **술 화면·검색 결과 사진으로도** 쓰입니다(지금 7종 모두 공식 사진이 없습니다). 사진은 양조장이 권리를 가진 것만 올려 주세요.

**③ 페어링 탭 — 우리 술에 어울리는 음식** (5분, 가장 중요)
- 술마다 어울리는 음식과 한 줄 이유를 적어 주세요(예: 백경53 × 육회 — "53도의 깔끔한 끝맛이 기름기를 잡아 줍니다"). 음식은 자유롭게 적으면 되고, 카탈로그에 같은 음식이 있으면 자동으로 이어집니다.
- 양조장이 적은 조합은 **"백경증류소 제공"** 근거로 술 화면 카드에 바로 실리고, 등급이 "근거 확인"으로 올라갑니다. 지금 백경15 블랙·향온, 세종소주28·46, 백경53은 근거 조합이 없어 "페어링 정보 준비 중"으로 보입니다 — 이 다섯 종부터 적어 주시면 좋겠습니다. 백경15 화이트(불고기·족발·보쌈·피자)와 골드(육전·갈비찜·족발·광어회)는 더술닷컴·블로그 근거가 이미 있습니다.

**④ 설정 탭 — 방문 시음 예약** (선택, 3분)
- 영업시간·회차 시각·한 회차 인원(양조장은 2명부터)을 정하고 "예약 받기"를 켜면 술 화면에 "양조장 방문 시음 예약" 상자가 붙고 손님이 바로 예약합니다. 예약은 즉시 확정이고 알림이 옵니다. 당장 안 받으셔도 됩니다.

**온라인 판매(선택)** — 주류 통신판매 승인이 있으시면 판매 탭 "온라인 판매 설정"에서 입점 신청을 할 수 있습니다. 결제(PG) 연결 전이라 지금은 상품·재고만 미리 올려 두는 단계입니다.

궁금한 점은 이 메일로 답장 주세요. 감사합니다.

## 2. 왜 이 순서인가 (운영자 메모)

- 사진 → 홈 파트너 줄·매장 화면·이달의 파트너 카드가 한 번에 좋아진다(사진 없는 파트너는 글자 동그라미, 2026-10-02 실측 유록·파르코·백경 모두 사진 없음).
- 술 표 사진 → 공식 사진 없는 술의 카드 사진 폴백(`shared/catalog/partner-images.ts`).
- 파트너 페어링 → official 90 근거(`packages/server/partner-pairings.ts`), 근거 없는 술이 "준비 중"에서 벗어나는 가장 빠른 길. 소믈리에 검수·AI 후보보다 빠르다.
- 예약은 켜야만 상자가 붙는다(`breweryPartner` — 승인 + 예약 받기 켬).

## 3. 식당·리쿼샵이면

- ①은 "매장 정보"(대표 사진·소개·주차·콜키지·룸·네이버 지도 링크 — 콜키지 금액을 적으면 "고른 술 가져가기" 순위에 들어간다).
- ②는 "판매" 메뉴판(음식·술 표, 메뉴판 사진 한 장이면 AI가 읽어 채운다 — 단, API 크레딧이 있을 때).
- ③은 식당도 같다(술 표·메뉴에서 고르거나 직접 입력, 근거는 "○○ 추천" official).
- ④는 자리 예약(식당)·방문 픽업(리쿼샵).
