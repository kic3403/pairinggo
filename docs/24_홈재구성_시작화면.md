# 24. 홈 재구성(캐치테이블·데일리샷 참고) + 시작 화면 (2026-09-25)

사용자가 준 캐치테이블·데일리샷 메인 화면 두 장을 분석해 **구조만** 가져왔다(사진·문구·아이콘은 복제하지 않음). 사용자 결정: 시작 화면 문구 "맛있는 술엔 맛있는 음식", 배너에 트렌드 리포트·이달의 파트너 양조장/매장·시즌/월별 이벤트, "많이 찾는 전통주" 마키는 홈에서 뺌.

## 1. 두 화면에서 가져온 것
| 요소 | 캐치테이블 | 데일리샷 | 페어링GO |
|---|---|---|---|
| 상단 | 로고 + 전폭 검색창 + 아이콘 | 지역 + 로고 + 아이콘 | 로고 + 전폭 검색창(휴대폰에서도, `SearchBox compact`) |
| 2단 탭 | 홈·야장지도·캐치단독… | 홈·한가위샷·공동구매… | 홈·전통주·위스키·사케·와인·음식·수상·핫한 페어링(`HomeTabs`, `HOME_TABS`) |
| 배너 | 옆 카드 살짝 보이는 캐러셀 + n/N 전체 | 전폭 사진 배너 + 행사 기간 | `HomeBanners` — scroll-snap 카드(82%, 데스크톱 3장), 배지·제목·부제·기간·버튼, "n/N 전체 ›" → `/events` |
| 아이콘 | 5열 그리드 + N 배지 | — | `QuickMenu` 5열×2줄(데스크톱 한 줄 10칸) |
| 서비스 타일 | — | 4장 색 타일 | `FlowTiles` — 술로 찾기·음식으로 찾기·식당 예약·양조장 방문 |
| 브랜드 줄 | — | 동그란 로고 캐러셀 | `PartnerRow` — 승인 파트너 대표 사진(매장 사진 → 술 사진), 업종 |
| 하단 | 탭바 + "작성할 리뷰 1" 알약 | 탭바 | 기존 탭바 + `TriedPill`("먹어봤나요? N", 로그인 회원, `/api/tried`) |
| 시작 화면 | 흰 바탕 로고 + 문구 1~2초 | — | `Splash` — 흰 바탕, 로고 + "맛있는 술엔 맛있는 음식", 1.2초 후 0.3초 페이드 |

## 2. 시작 화면 규칙
- 서버 렌더 + CSS 애니메이션(`.splash`, `@keyframes splash-out`). 한 탭에 한 번: `layout.tsx`가 `<head>` 앞에 심는 인라인 스크립트가 `sessionStorage.pg_splash`를 보고 `<html class="no-splash">`를 첫 그리기 전에 붙인다 → 새로고침·뒤로가기·앱 라우터 이동엔 안 뜬다. 어드민·파트너 앱은 없음. `prefers-reduced-motion`이면 0.6초 후 바로. `aria-hidden`. 매니페스트 `background_color` 흰색(설치 앱의 시스템 스플래시와 이어짐).

## 3. 배너 데이터
- 표 `home_banners`(0036): kind(event·partner·report·custom)·title·subtitle·badge·cta·href(사이트 안 주소만)·tone(6색)·image_url(우리 저장소만)·merchant_id·starts_on·ends_on·sort·active. 되돌리기 `drop table home_banners`.
- 규칙 `shared/home/banners.ts`(테스트 `banners.test.ts`): `cleanBanner`(제목 2자·링크 `/`로 시작·기간 순서·색·사진 주소), `activeBanners(rows, today)`(KST 오늘, sort → 끝 임박 → id), `bannerCards`(리포트 자동 카드 맨 앞 → 어드민 카드 → 2장 미만이면 상시 카드), `periodText`("9/14(월) ~ 9/27(일)"), `reportCard`, `DEFAULT_CARDS`, `HOME_TABS`, `FLOW_TILES`.
- 서버 `lib/banners.ts`: `homeCards`(배너 + 승인 파트너 목록 `partnerList` — 사진 있는 곳 먼저), `allEventCards`(`/events`), `saveBanner`·`deleteBanner`. 어드민 `/admin/banners` + `POST/DELETE /admin/api/banners`(저장 시 `revalidatePath("/")`로 홈 즉시 반영).
- 파트너 카드는 매장을 고르면 이름·업종·대표 사진·문구("이달의 파트너 양조장 · 방문 시음 예약")가 자동, 제목·부제·버튼을 적으면 덮어쓴다.

## 4. 홈 순서(`app/(site)/page.tsx`)
한 줄 소개(h1) → `HomeTabs` → `HomeBanners` → `QuickMenu` → `FlowTiles` → `PartnerRow` → `TrendRow`(정지 카드) → 음식 종류 칩 → 회원 추천 → 안주로 찾기 → `TriedPill`. 뺀 것: 히어로 문장·숫자 3개·마키(`HeroMarquee` 파일은 남겨 둠, 미사용)·큰 버튼 2개·report-card.
- 부품 통일: 칩(`.tabs a`·`.fchip`·`.chip-more`) 높이 40·글자 600·선택 남색 채움, 홈 카드 여백 14px, 이름만 700.

## 5. 검증(2026-09-25)
- Vitest 460 통과, 웹 타입 검사 통과. 로컬 캡처: 시작 화면 → 홈(390·360·1280), 같은 탭 두 번째 열기엔 시작 화면 없음, 배너 3장(리포트·이벤트·한증류소) 스와이프·카운터, 아이콘 10칸, 타일 4장, 파트너 줄, 트렌드 카드, `/events`, 어드민 배너 추가(잘못된 링크·제목 거부, 미로그인 401).
- 시범 배너 2장(가을 전통주 주간 이벤트 9/20~10/10 · 이달의 파트너 양조장 한증류소)은 운영 DB에 있다 — 어드민에서 고치거나 끄면 된다.

## 6. 상세 화면 정리 (2026-09-25)
- 술 상세: ① 머리 카드 `.dhead`(사진 · 이름 · 원어명 · 분류 · 외부 평점 · 맛/수상 태그 · 저장/공유) → 설명 한 줄 → 규격·참고가격 → 입점 구매 → ③ 구매 칸(버튼 + 안내 한 줄 + 현장 판매 + **"내 주변 판매점 찾기"는 접어 둠**(`details.fold`, 온라인 불가 주류는 펼침) → ④ 맛 프로필·주종별 정보 나란히(`.dinfo`) → 어울리는 음식(등급 설명은 "어울림 등급은 어떻게 매기나요" 접기) → 옆 칸은 파트너 양조장 + **관련 술 한 칸**(같은 양조장·비슷한 술·같은 지역, 각 4개). '데이터' 칸·공유 줄·본문 저장 버튼 중복은 뺐다.
- 음식 상세: 머리 카드(이름·분류·태그·공유 + 맛 프로필 옆), 등급 설명 접기, '데이터' 칸 제거. 맛집 찾기 칸은 그대로(저장 버튼 포함, 2026-09-14 사용자 결정).

## 7. 목록 화면 정리 (2026-09-26)
- `/drinks`: 본문 검색창 제거(헤더 검색창이 어디서나 있음), 제목 옆 한 줄 설명은 주종을 골랐을 때만(휴대폰은 숨김), 종류 설명 문장은 데스크톱만, 세부 칩은 한 줄 가로 스크롤, "가격 확인된 술만" 안내는 결과 수 옆 짧게(툴팁에 기준), 결과 수·정렬은 한 줄(데스크톱은 필터 버튼 줄 오른쪽).
- 카드: 이름만 주황·분류 줄은 회색, 휴대폰에서는 이름·분류·규격 3줄(음식·맛 태그는 640px 이상만), 타일 글자는 전통주 종류(탁주…), 같은 줄 카드 높이 맞춤.

## 8. 상세 머리 카드 사진 칸 (2026-09-26)
- 사용자 요청: 검색해 들어온 술·음식의 사진이 머리 카드(`.dhead`) **오른쪽 빈 자리**에 들어가게. 부품 `_components/DetailMedia.tsx` — 사진이 있으면 사진(술은 병이 잘리지 않게 contain, 음식은 cover) + 출처 한 줄, 없으면 **같은 크기의 자리표시 타일**(주종·분류 색 `KIND_TONE` + 병/그릇 실루엣 + 종류 이름 + "사진 준비 중")이라 사진 유무와 무관하게 카드 모양이 같다. 목록 카드 타일 색(`DrinkCard`)도 같은 표를 쓴다.
- 크기: 휴대폰 96px, 640px부터 160px, 세로 3:4. 음식은 900px부터 본문·맛 프로필·사진 셋 나란히(`.dhead:has(.pbars)` 3열), 그 아래 폭에서는 맛 프로필이 카드 아래 줄 전체.
- 음식 사진 데이터: `foods.image_url·image_credit`(0037) → `Food.image`(`rows.ts foodFromRow`). 검색 결과 음식 줄에도 썸네일(`.row-img`).
- 입력: 어드민 `/admin/drinks/[id]`에 **사진 주소·출처 칸**(공식 사진, 비우면 파트너 매장 사진 폴백 → 타일), 새 화면 `/admin/foods`(줄마다 주소·출처 저장, "사진 없음" 필터) + `POST /admin/api/foods`. 주소 규칙 `shared/catalog/images.ts cleanCatalogImage`(https 절대 주소 또는 `/…` 사이트 안 경로만, 300자, 공백·따옴표·꺾쇠 금지) — 잘못된 주소는 술은 비우고 알림, 음식은 400. 사용 허락을 받은 사진만(더술닷컴 aT 사진 금지)은 사람의 몫.
- 검증: Vitest 464 통과, 웹 타입 검사 통과, 로컬 캡처(이강주 = 타일, 데모 와인 = 사진, 해물파전 = 타일/시험 사진, 390·768·1280), 어드민 음식 사진 저장·잘못된 주소 거부·미로그인 401 확인 뒤 시험 사진 삭제.
