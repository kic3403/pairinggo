### 1-2. 코드 (`앱 파일/pairinggo-nextjs_4/pairinggo`)

- Next.js 16 · React 19 · Tailwind v4 · TypeScript. git은 초기 커밋 1개.
- 페이지 8개: 홈, drink/[id], food/[id], restaurants, related, saved + API `/api/restaurants` (Google Places Text Search, 키 없으면 mock).
- 컴포넌트 12개: SearchBox(초성·별칭 검색), PairingList(전문가/대중 탭), RestaurantFinder, RegionPicker, RegionDrinks, SaveButton, NearbyLink, PlaceMemo, RecentTracker, SavedView, RelatedView, BottomNav.
- `lib/data.ts`: 검색·유사도·초성, `lib/rating.ts`: 베이지안 별점 보정·거리, `lib/prefs.ts`: localStorage 상태.
- `scripts/check-links.mjs` + GitHub Actions 주간 링크 점검.

**재사용 판단**: 검색 로직·초성 처리·별점 보정·페어링 카드 UI·데이터 타입은 그대로 이식. 페이지 라우팅과 API 라우트는 새 구조에 맞춰 재작성.

## 2. 최종 목적과의 간극 (보완이 필요한 레이어)

```
현재:   검색 → 근거 있는 추천 → [외부 링크] 구매 / [외부 링크] 예약
목표:   검색 → 근거 있는 추천 → 앱 내 결제·배송 추적 / 앱 내 예약·확정·방문
```

| 레이어 | 문서 상태 | 필요한 것 |

| 회원·인증 | 없음 | 토스 로그인, 토스 인증(이름·생년월일·CI) 기반 만 19세 확인, 사용자 테이블 |
| 커머스 | "판매 중개 없음" | 파트너(양조장) 입점·상품·재고, 장바구니, 토스페이 결제, 주문·배송 상태, 정산(지급대행), 반품·CS |

## 3. 외부 조사 결과 (2026-09-08 확인)

### 3-1. 토스 앱인토스 플랫폼 제약

| 항목 | 내용 | 계획 반영 |
|---|---|---|
| 렌더링 | **SSR 불가. CSR 또는 SSG 정적 번들만** 업로드 (`npx ait deploy`) | 프론트/백엔드 분리 (04) |
| 로그인 | **토스 로그인만** 허용. 소셜·자체 로그인 금지. 인가코드→토큰 교환은 서버에서 | 인증 설계 (04) |
| 본인확인 | 토스 인증 '본인 확인' 제공: 이름·생년월일·휴대전화·**CI** | 성인인증 (03·04) |
| 결제 | **실물 상품은 토스페이만**. 토스페이먼츠 등 PG 직접 연동 금지. 디지털 상품은 인앱결제 | 결제 설계 (04) |
| 토스페이 | 앱인토스 전용 가맹점 키 별도 발급, 7~14 영업일. **PG 라이선스 없으면 정산대행 계약(예: 토스페이먼츠) 선행** | Stage 0 트랙 (05·06) |
| 외부 링크 | 외부 결제창·외부 의존 구조 금지. 예외: "제품 소개·추천 후 구매 플랫폼으로 이동", 법률 고지, 제휴기관 공식 페이지 | Stage 1은 '추천 서비스'로 등록해 링크 허용, Stage 2부터 앱 내 구매 |
| 위치 | `Device.getLocation` / `subscribeLocation` SDK 제공, 권한 다이얼로그 API 있음 | 식당 찾기 |
| 푸시 | 기능성 푸시 무료, 광고성은 수신 동의·비즈월렛 과금, 일 10만 명 | 예약·주문 알림 |

| 사업자 | 없이도 출시 가능하나 로그인·결제·정산은 사업자 필수. 간이과세자 정산 가능 | Stage 0 |
| 검수 | 앱 등록 1~2일, 출시 검수 비게임 **1~3개월** | Stage 1 조기 제출 |
| 쇼핑몰 요건 | 고객센터·가품 방지·환불 정책 없으면 출시 불가 | 06 체크리스트 |

### 3-2. 전통주 통신판매 법적 구조

| 항목 | 내용 |
|---|---|
| 판매 주체 | 전통주 제조자(지자체 추천 + **관할 지방국세청장 승인**)만 통신판매 가능. 소비자 대상 홈페이지·앱으로 주문·결제·인도 |
| 플랫폼 지위 | **통신판매 수단제공자**: 주류를 자기 책임으로 사고팔지 않고, 대금을 자기 책임으로 수령하지 않으며, 제조자가 직접 배송하면 **주류 면허 불필요** (국세청 유권해석) |
| 성인인증 | 판매 시 성인 확인 필수 (토스쇼핑 정책도 전통주를 '성인인증 필요 상품'으로 분류) |
| 판촉 제한 | 주류 할인 10% 이내, 사은품은 거래금액 10% 이내, 시음주·주류 교환권 불가 (토스쇼핑 기준 = 국세청 주류 거래질서 기준) |
| 토스페이 입점 제한 | '청소년유해약물'이 제한 목록에 있음 → **전통주 취급 가능 여부를 토스페이 청약 전 서면 확인** (토스쇼핑은 전통주 예외 허용 → 가능성 높음) |
| 스마트오더 | 소매업자(바틀샵·편의점·음식점)가 별도 승인 없이 앱 주문 → **매장 대면 인도**만 가능, 배달 불가. 플랫폼이 별도 장소에서 인도하면 위반 |

### 3-3. 시사점

1. **앱인토스 선택은 옳지만 '웹앱 하나로 다 한다'는 전제는 깨진다.** 미니앱(정적) + 백엔드/어드민(서버)의 2-앱 구조가 필수.
2. **전통주 중개는 법적으로 열려 있고, 인증·결제 인프라는 토스가 제공한다.** 남은 병목은 사업자·정산대행·토스페이 계약(약 4~6주)과 양조장 입점 계약.
3. **검수 1~3개월**이 가장 긴 리드타임 → Stage 1(추천+링크)을 먼저 제출해 검수를 돌리는 동안 Stage 2(커머스)를 개발.
4. 현재 '구매 링크 이동'은 앱인토스 예외 조항("추천 후 구매 플랫폼 이동")에 해당하므로 Stage 1에서도 통과 가능. 단 '구매하기'를 앱 내 기능으로 등록하는 순간 앱 내 완결 의무 발생.
