# 06. 법무 · 운영 체크리스트

개발과 병행하는 비개발 트랙. 각 항목의 **선행 관계**가 결제·예약 기능의 출시 시점을 정한다.

## 1. 사업자·플랫폼 계약 (Stage 0, 즉시 시작)

| # | 항목 | 담당·기관 | 리드타임 | 선행 | 상태 |
|---|---|---|---|---|---|
| 1 | 사업자등록 (개인 → 필요 시 법인 전환). 업태: 서비스·도소매 / 종목: 전자상거래 소매중개업, 응용소프트웨어 개발·공급 | 홈택스 | 1~3일 | — | ☐ |

| 3 | 앱인토스 콘솔 워크스페이스 생성 + 사업자 등록 + 미니앱 등록 (카테고리: 추천·정보 → Stage 2에 쇼핑 추가) | 앱인토스 콘솔 | 1~2일 | 1 | ☐ |
| 4 | 정산대행 서비스 계약 (토스페이먼츠 등) — "PG 라이선스 없으면 토스페이 청약 전 선행". 플랫폼(중개) 유형·하위 판매자 지급대행 가능 여부 확인 | 토스페이먼츠 | 1~2주 | 1,2 | ☐ |

| 8 | 카카오 알림톡 발신 프로필 + 템플릿 심사 (주문·예약 알림) | 카카오 비즈니스 / 발송 대행사 | 1~2주 | 1 | ☐ |
| 9 | 상표 검색·출원 (페어링GO, 워드마크) | 키프리스 / 변리사 | 출원 1주, 등록 6~12개월 | — | ☐ |

## 2. 주류 규제

| # | 항목 | 근거 | 적용 |
|---|---|---|---|
| 1 | 판매자 = 전통주 제조자(지방국세청 통신판매 승인). 플랫폼은 수단 제공만 | 주류의 통신판매에 관한 명령위임 고시, 국세청 유권해석 | 입점 계약서에 승인서 사본 첨부 의무, 미승인 양조장은 링크 안내만 |
| 2 | 플랫폼은 주류를 자기 책임으로 매입·판매·대금 수령하지 않음 | 동 고시 | 정산대행 통해 판매자 직접 지급, 재고는 판매자 소유 |
| 3 | 성인인증 필수 (만 19세) | 청소년보호법, 고시 | 토스 인증 CI 기반, 구매·예약 진입 시 게이트, 12개월 재확인 |
| 4 | 수령 시 성인 확인 | 배송 실무 | 판매자·택배사 '성인 확인 배송' 옵션 사용 권고, 주문서 고지 |
| 5 | 온라인 판매 불가 주류(일반주류 7종 등) 등록 차단 | 주세법 | `drinks.online_sellable=false` → 상품 등록 UI 차단, 스마트오더 단계에서만 |
| 6 | 주류 할인 10% 이내, 사은품 10% 이내, 시음주·주류 교환권 불가 | 주류 거래질서 고시, 토스쇼핑 정책 | 쿠폰·프로모션 엔진에 상한 하드코딩 |
| 7 | 주류 광고 경고문구 ("지나친 음주는 …") 상시 표시, 미성년 대상 표현 금지, 음주 미화 금지 | 국민건강증진법 §7, 시행령 | 상품·홈 화면 푸터, 푸시 문구 검수 |
| 8 | 스마트오더(Stage 4): 소매업자 판매, 매장 대면 인도만, 배달 금지 | 국세청 스마트오더 허용 고시 | 픽업 QR·매장 인도 확인 플로우, 배송 옵션 없음 |
| 9 | 청약철회: 주류는 개봉·훼손 시 환불 불가 사전 고지, 파손·오배송은 판매자 책임 | 전자상거래법 §17 | 주문서 고지 체크박스 + 환불 정책 페이지 |

## 3. 플랫폼·소비자 보호

| # | 항목 | 근거 | 적용 |
|---|---|---|---|
| 1 | 통신판매중개자 고지 — "페어링GO는 통신판매중개자이며 거래 당사자가 아님", 판매자 신원(상호·대표·사업자번호·연락처·주소) 상품 페이지 표시 | 전자상거래법 §20 | 상품 상세·주문서·약관 |
| 2 | 이용약관 · 개인정보처리방침 · 위치기반서비스 이용약관 | 개인정보보호법, 위치정보법 | 랜딩(웹)에 게시 + 앱인토스 콘솔 등록 |
| 3 | 위치기반서비스사업 신고 — 소상공인·1인 창조기업 면제 특례 해당 여부 확인, 해당 시 면제·비해당 시 방통위 신고 | 위치정보법 §9 | Stage 1 위치 기능 활성화 전 확인 |
| 4 | 개인정보: 수집 최소화(토스 로그인 동의 범위 최소), CI 해시 보관, 배송지 90일 후 마스킹, 파기 절차, 처리방침에 수탁사(Supabase·Vercel·알림톡) 명시 | 개인정보보호법 | 04 문서 보안 항목 |
| 5 | 앱인토스 쇼핑몰 요건: 고객센터·가품 방지·환불 정책 | 앱인토스 정책 | S19 고객센터, 판매자 검증(승인서), 환불 정책 페이지 |
| 6 | 앱인토스 외부 링크 정책: Stage 1 '추천 후 구매 플랫폼 이동' 예외, 법적 고지·제휴기관 공식 페이지만 외부 | 앱인토스 정책 | 링크 아웃 화이트리스트 관리 |
| 7 | 예약 이용약관: 노쇼·취소 정책, 예약금 환불 기준, 매장 귀책 시 보상 | 공정위 소비자분쟁해결기준(외식) | 예약 화면 고지, 매장별 정책 설정 범위 제한 |
| 8 | 리뷰 정책: 검증 구매·방문만 작성, 대가성 표시, 삭제 기준 | 표시광고법 | 리뷰 작성 조건, 신고 처리 |
| 9 | 생성형 AI 고지: AI 생성 페어링에 표시 | 앱인토스 2-4 정책 | `source: ai` 배지 + 안내 문구 |

## 4. 파트너 계약

| 문서 | 핵심 조항 |
|---|---|
| 양조장 입점 계약 | 판매자 지위·책임(상품 정보·배송·CS·청약철회), 통신판매 승인서·사업자등록증 제출, 수수료율·정산 주기(월 2회), 판촉 상한, 재고·품절 관리 의무, 개인정보 위탁, 해지 |
| 식당 입점 계약 | 예약 정보 정확성, 승인 응답 SLA(2시간), 노쇼·취소 정책 범위, 수수료(시범 0 → 건당), 메뉴·페어링 정보 게시 동의, 리뷰 정책 |
| 바틀샵 스마트오더 계약 (Stage 4) | 소매 면허 확인, 대면 인도 의무·미성년 판매 금지, 픽업 재고 관리, 수수료 |
| 개인정보 처리 위탁 계약 | 배송지 등 소비자 정보 처리 범위·보관 기간 |

## 5. 운영 체계 (1인 운영 기준)

| 영역 | 도구 | 규칙 |
|---|---|---|
| CS | 카카오 채널 + 앱 내 1:1 문의(어드민 큐) | 24시간 내 1차 응답, 환불은 판매자 확인 후 48시간 내 처리 |
| 주문 모니터 | 어드민 대시보드 + 이상 알림(결제 성공·주문 상태 불일치, 24시간 미발송) | 매일 오전 점검 |
| 예약 모니터 | 승인 지연(2시간) 자동 리마인드 알림톡, 노쇼율 주간 리포트 | 매장 노쇼율 20% 초과 시 예약금 필수 전환 권고 |
| 정산 | 월 2회 정산 배치 → 정산대행 지급 → 어드민 대조 | 오차 0 원칙, 불일치 시 지급 보류 |
| 데이터 검수 | 인기 검색어 상위 20개 주간 검수, AI 페어링 승격 | 검수 로그 보관 |
| 링크 점검 | 기존 `check-links` 주간 크론 유지 | 실패 링크 자동 비노출 |
| 장애 | Sentry 알림, Supabase·Vercel 상태 | 결제 장애 시 결제 버튼 비활성 + 안내 |
