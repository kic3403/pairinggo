# 02. 서비스 전략 · 비즈니스 모델 · 법적 구조

## 1. 포지셔닝

> **"이 술엔 뭘 먹지? 이 음식엔 뭘 마시지?"에 근거로 답하고, 그 자리에서 술을 사고 식당을 잡는다.**

| | 데일리샷 | 캐치테이블 | 페어링GO |
|---|---|---|---|
| 출발점 | 술 (위스키·와인 픽업) | 식당 (예약·웨이팅) | **술↔음식 조합** |
| 추천 근거 | 판매량·큐레이션 | 별점·리뷰 | **양조장·소믈리에·매체 출처 + 맛 프로필 + 대중 언급량** |
| 거래 | 스마트오더 픽업 | 예약·예약금 | **전통주 직배송(1) + 바틀샵 픽업(2) + 식당 예약** |
| 주류 강점 | 수입 주류 | — | **전통주 (온라인 직배송 유일 합법 카테고리)** |
| 유통 | 자체 앱 | 자체 앱 | **토스 앱 안 (앱인토스)** — 설치 없이 진입, 토스 인증·결제 내장 |

**차별화의 핵심은 두 가지**: ① 추천에 출처가 붙는 투명성(데이터 자산 851건), ② 추천이 끝난 지점에서 거래가 시작되는 동선. 둘 중 하나만으로는 데일리샷·캐치테이블과 싸울 수 없고, 둘을 합친 자리는 비어 있다.

## 2. 타깃 사용자

| 세그먼트 | 상황 | 페어링GO가 주는 것 | 첫 거래 |
|---|---|---|---|
| 전통주 입문자 (25~39) | 선물·홈파티·데이트에 전통주를 사고 싶은데 뭘 골라야 할지 모름 | "이 음식이면 이 술" 근거와 함께 → 바로 구매 | 전통주 구매 |
| 술자리 기획자 | 오늘 모임 메뉴·장소를 정해야 함 | 음식 → 어울리는 술 → 그 음식 파는 예약 가능한 식당 | 식당 예약 |
| 전통주 애호가 | 특정 양조장·수상작을 찾음 | 108종 상세·수상·직판 정보·주변 판매점 | 구매·양조장 방문 |
| 토스 사용자 (유입 채널) | 토스 앱 안에서 발견 | 설치 없이 검색 1회로 가치 체감 | 검색 → 저장 |

## 3. 단계별 비즈니스 모델

### Stage 1 — 추천 서비스 (수익 0, 데이터·검수·트래픽 확보)
- 앱인토스 '추천·정보' 카테고리로 등록. 구매 링크는 "추천 후 구매 플랫폼 이동" 예외로 허용.
- 목표: 주간 검색 300건, 인기 검색어 상위 20개 검수, 양조장 입점 대기열 10곳.

### Stage 2 — 전통주 구매 중개 (첫 수익)
| 수익원 | 구조 | 가격 초안 |
|---|---|---|
| 판매 수수료 *(2026-09-21 변경 — **시범 3개월 0% → 5%**, 근거·조정 조항은 docs/22 §3)* | 양조장(판매자) 판매가의 일정률. 토스페이 결제 수수료는 별도(정산대행 조건에 따라 판매자 부담/플랫폼 부담 결정) | **8~10%** (네이버 스마트스토어 5~6% + 노출·근거 콘텐츠 가치 반영). 시범 입점 10곳은 **3개월 0%** |
| 노출 상품 | 페어링 결과 상단 '양조장 추천' 표시, 오늘의 페어링 지정 | 월 정액 10~30만 (Stage 3 이후) |

### Stage 3 — 식당 예약 (거점 지역 밀도 확보)
| 단계 | 과금 | 조건 |
|---|---|---|
| 3-a 시범 | **입점 무료, 수수료 0** | 거점 구 10~20곳, 경량 예약(요청→승인) |
| 3-b 유료화 | **확정 예약 건당 수수료** 500~1,000원 또는 예약금 결제액의 3~5% | 즉시확정·예약금 기능 오픈 후 |
| 3-c 구독 전환 | 월 3.3만~9.9만 구간제 (캐치테이블 벤치마크) | 월 예약 30건 이상 매장부터 선택 전환 |

### Stage 4 — 확장
- 바틀샵 스마트오더(픽업) 수수료 · 와인·위스키 카탈로그 · 배너/추천 광고(앱인토스 광고 SDK) · 페어링 코스 프로모션(양조장×식당 B2B).

### 수익 시뮬레이션 (보정판 — 검증 전 가정치)
| 시점 | 구매 | 예약 | 광고·노출 | 월 합계 |
|---|---|---|---|---|
| 출시 6개월 | 양조장 15곳 · 월 400건 × 3.5만 × 8% = 112만 | 시범 무료 | 0 | 약 110만 |
| 12개월 | 양조장 40곳 · 월 1,500건 × 3.5만 × 8% = 420만 | 식당 60곳 · 월 900건 × 800원 = 72만 | 30만 | 약 520만 |
| 24개월 | 양조장 80곳 + 바틀샵 픽업 · 월 5,000건 × 3.5만 × 8% = 1,400만 | 식당 300곳 구독 평균 4.4만 = 1,320만 | 300만 | 약 3,000만 |

기획서 v4의 "12개월 월 1,300만"은 예약 구독 100곳을 전제로 했으나, 제휴 0곳·1인 운영에서는 구매 수수료를 먼저 세우는 편이 현실적이다. 분기마다 실적으로 재보정한다.

## 4. 법적 구조 — 통신판매 수단제공자 모델

```
소비자 ──(토스 로그인·토스 인증 성인확인)──▶ 페어링GO 미니앱
   │ 주문·결제(토스페이)                          │ 주문 전달
   ▼                                              ▼
토스페이 ──▶ 정산대행(토스페이먼츠 등) ──▶ 양조장(판매자) 계좌  ※ 플랫폼 수수료 차감 정산
                                                  │ 직접 배송
                                                  ▼
                                               소비자
```

| 당사자 | 지위 | 의무 |
|---|---|---|
| 양조장 | **판매자** (전통주 제조자, 지방국세청 통신판매 승인 보유) | 상품 정보·가격 책정, 재고, 포장·배송, 청약철회 대응 |
| 페어링GO | **통신판매중개자 + 주류 통신판매 수단제공자** | 판매자 신원 고지(전자상거래법 §20), 성인인증, 주문 전달, 분쟁 조정 창구, 주류 광고 규정 준수. 주류를 자기 책임으로 매입·판매·대금 수령하지 않음 |
| 결제·정산 | 토스페이(결제수단) + 정산대행사 | 대금 수령·판매자 지급대행 (플랫폼이 대금을 자기 계좌로 받지 않는 구조 유지) |
| 소비자 | 만 19세 이상 | 성인인증, 수령 시 신분 확인(배송사 정책) |

**반드시 확인할 것 (Stage 0)**
1. 세무사 또는 국세청 사전 질의로 위 구조가 '수단제공자' 요건을 충족하는지 서면 확인.
2. 토스페이 청약 시 전통주 취급 가능 여부 서면 확인 (토스페이 입점 제한에 '청소년유해약물' 포함).
3. 입점 양조장의 **주류 통신판매 승인서 사본** 확보를 입점 조건으로 계약서에 명시.
4. 온라인 판매 불가 7종(화요·일품진로·백세주 등 일반주류)은 Stage 2에서 상품 등록 차단, Stage 4 스마트오더에서만 취급.

### 스마트오더(Stage 4) 구조
- 판매자 = 바틀샵(주류 소매업 면허), 소비자가 앱에서 주문·결제 → **매장 방문·대면 인도**. 배달·택배 절대 불가.
- 매장 재고 연동이 관건 → 바틀샵 어드민에서 "픽업 가능 상품·수량"만 관리하는 경량 재고로 시작.

## 5. 초기 거점 지역 선정 기준 (서울 특정 구)

| 기준 | 가중치 | 마포 (홍대·연남·망원) | 종로 (익선·서촌·광장시장) | 강남 (역삼·논현) |
|---|---|---|---|---|
| 전통주 주점·바틀샵 밀도 | 30% | 높음 (전통주 바 다수) | 높음 (한식·주점 전통) | 중간 |
| 타깃 연령 유동인구 (25~39) | 25% | 매우 높음 | 중간 | 높음 |
| 소규모 자영 식당 비율 (입점 설득 용이) | 25% | 높음 | 높음 | 낮음 (프랜차이즈·대형) |
| 페어링 데이터 음식과의 적합도 (한식·전·회) | 20% | 중간 | **높음** | 중간 |

**권장: 마포 또는 종로 중 발로 뛸 수 있는 곳.** 선정 후 카카오 로컬로 반경 1.5km 내 '전통주·막걸리·한식 주점' 후보 100곳을 뽑아 영업 리스트를 만든다(05 로드맵 영업 트랙).

## 6. 리스크와 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| 앱인토스 검수 지연·반려 (1~3개월) | 출시 지연 | Stage 1을 최소 범위로 조기 제출, 반려 사유 대응 버퍼 2주 |
| 토스페이가 전통주를 거절 | 앱 내 결제 불가 | Stage 0에서 서면 확인. 거절 시 독립 PWA(토스페이먼츠 직접) 병행 출시로 전환 — 미니앱은 추천+링크 유지 |
| 양조장 입점 저조 | 상품 부족 | 데이터에 있는 76곳 직판 양조장 + 수상작 47종 양조장부터 접촉. "이미 등록·노출 중" 근거 제시. 시범 3개월 수수료 0 |
| 예약 매장 확보 실패 | 예약 기능 무의미 | 거점 1개 구 집중, 입점 무료·건당 과금, 매장용 '페어링 메뉴 노출' 혜택 선제공 |
| 배송 사고·품질 분쟁 | CS 부담 | 판매자 책임 원칙 계약, 앱 내 CS 창구·환불 정책(앱인토스 쇼핑몰 요건) |
| 노쇼 | 매장 신뢰 하락 | 예약금 옵션, 노쇼 이력 기반 예약 제한, 리마인드 푸시 |
| AI 페어링 품질 | 추천 신뢰 훼손 | 851건 큐레이션 우선, AI는 미등록 검색어 폴백 + 검수 승격 파이프라인 |
| 1인 운영 과부하 | 속도 저하 | 어드민 자동화·알림 우선 개발, 영업은 이메일·카카오 채널 템플릿화 |
