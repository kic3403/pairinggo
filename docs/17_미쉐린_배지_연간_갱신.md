# 미쉐린 배지 · 블루리본 링크 — 연간 갱신 절차 (2026-09-12)

음식 상세의 "주변 음식점" 결과에서 미쉐린 가이드 선정 식당은 이름 옆에 **자체 별 아이콘 + 연도** 배지(예: `미쉐린 ★★ 2026`, `미쉐린 빕구르망 2026`)가 붙고,
목록 아래에 "미쉐린 가이드 서울&부산 2026 기준" 출처가 적힌다. 모든 식당 카드에는 "블루리본 확인 ↗" 링크가 있다(블루리본 서베이 검색으로 이동).

## 원칙
- 미쉐린 **로고·미쉐린맨 그림은 쓰지 않는다**(상표). 별은 우리가 그린 ★ 문자, 출처는 글자로.
- 표에 넣는 것은 "어느 식당이 어떤 등급을 받았다"는 공개 사실과 공식 페이지 링크뿐. 가이드의 소개 문장·사진은 넣지 않는다.
- 블루리본 서베이는 데이터베이스 제작자 권리·약관 때문에 **계약 전에는 목록을 가져오지 않는다**. 계약이 되면 `restaurant_awards`에 `guide='blueribbon'`으로 같은 방식으로 넣고, 그쪽 표시 지침에 맞춰 배지를 만든다. 그전까지는 검색 링크만.
- 대조 규칙(`packages/shared/src/awards.ts`): 이름 정규화 일치(또는 포함) + 좌표 300m 안. 두 글자 이하 이름은 완전 일치 + 좌표 필수(“산”, “소울”이 엉뚱한 곳에 붙지 않게).

## 매년 (발표는 보통 2~3월)
1. 발표 뒤 공식 사이트에서 새 연도 목록을 받는다. 서버에서는 403이 나므로 **크롬에서 열어** 아래 스니펫을 개발자도구 콘솔에 붙여 넣는다(서울 스타 3페이지·빕 구르망·부산). 카드에 좌표(`data-lat/lng`)가 들어 있다.
   ```js
   const parse = d => [...d.querySelectorAll('.js-restaurant__list_items > div')].map(el => { const a = el.querySelector('a[href*="/restaurant/"]'); const dd = el.querySelector('[data-lat]') || el; return { name: (el.querySelector('.card__menu-content--title, h3')?.textContent || '').replace(/\s+/g, ' ').trim(), lat: +dd.getAttribute('data-lat'), lng: +dd.getAttribute('data-lng'), url: 'https://guide.michelin.com' + a?.getAttribute('href') }; }).filter(x => x.name);
   const pages = { '서울|star|3': '/kr/ko/seoul-capital-area/kr-seoul/restaurants/3-stars-michelin', '서울|star|2': '/kr/ko/seoul-capital-area/kr-seoul/restaurants/2-stars-michelin', '서울|star|1': '/kr/ko/seoul-capital-area/kr-seoul/restaurants/1-star-michelin', '서울|bib|0': '/kr/ko/seoul-capital-area/kr-seoul/restaurants/bib-gourmand', '부산|star|1': '/kr/ko/busan-region/busan_1025838/restaurants/1-star-michelin', '부산|bib|0': '/kr/ko/busan-region/busan_1025838/restaurants/bib-gourmand' };
   const items = [];
   for (const [k, p] of Object.entries(pages)) { const [city, kind, level] = k.split('|'); for (let n = 1; n <= 4; n++) { const r = await fetch('https://guide.michelin.com' + p + (n > 1 ? '/page/' + n : '')); if (!r.ok) break; const got = parse(new DOMParser().parseFromString(await r.text(), 'text/html')); if (!got.length) break; items.push(...got.map(x => ({ ...x, city, kind, level: +level }))); if (got.length < 20) break; } }
   copy(JSON.stringify({ guide: 'michelin', edition: '미쉐린 가이드 서울 & 부산 2027', year: 2027, published: '2027-03-01', source: 'https://guide.michelin.com/kr/ko', items }, null, 2));
   ```
   (부산 경로 `busan_1025838`은 사이트가 바꿀 수 있다. 404면 부산 페이지를 열어 주소를 확인.)
2. 붙여 넣은 JSON을 `packages/db/research/michelin-2027.json`으로 저장하고 개수를 확인한다(2026: 서울 3★1·2★10·1★31·빕51, 부산 1★4·빕20 = 117).
3. 넣는다:
   ```bash
   pnpm --filter @pairinggo/db awards research/michelin-2027.json --dry   # 개수 확인
   pnpm --filter @pairinggo/db awards research/michelin-2027.json         # 그 연도 행 교체
   ```
4. 화면은 최신 연도만 쓴다(`apps/web/lib/awards.ts`가 `max(year)`를 읽음). 이전 연도 행은 남겨 두어도 표시에 영향 없다. 서버 캐시는 1시간, 재배포하면 즉시.
5. 커밋: research JSON + 이 문서의 연도 숫자.
