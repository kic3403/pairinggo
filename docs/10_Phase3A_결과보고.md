### 알려진 한계 (다음 단계에서)
- 카카오 로컬에 **별점이 없어** 거리순·정확도순만 제공. 자체 별점은 Stage 3 리뷰 이후, 그전엔 "언급량"도 식당 단위 데이터가 없음
- 거리순은 키워드 관련도가 낮은 가까운 가게(고기집 등)가 위로 올 수 있음 → 정확도순 토글로 보완, 추후 카테고리 가중
- 토스 앱 안의 실제 웹뷰 도메인은 첫 실기기 테스트에서 확인해 카카오 JS SDK 도메인에 추가해야 지도가 뜸
- 판매점 검색은 키워드 기반이라 누락·잡음이 있음 → Stage 4 바틀샵 입점 데이터로 대체

## 3. 사용자가 할 일 (3-B 진입 조건)
1. 앱인토스 콘솔 가입 → 워크스페이스 → 미니앱 등록(appName `pairinggo`) — 토스 로그인·푸시·검수 제출의 전제
2. 등록 후 토스앱 테스트에서 **웹뷰 도메인** 확인 → 카카오 [JavaScript SDK 도메인]에 추가, `apps/web/.env.local`의 `ALLOWED_ORIGINS`에도 추가
