# 안주 사진 생성 목록 (2026-10-03)

사진이 없는 안주 **119종**(카탈로그 143종 중 24종은 2026-10-03 캔바 AI로 완료). 근거 조합이 많은 순서라 **위에서부터** 만들면 화면에 먼저 드러나는 음식부터 채워진다.

## 1. 만드는 방법 (ChatGPT)

1. ChatGPT(이미지 생성 가능한 모델)에 아래 **공통 지시**를 먼저 한 번 붙여 넣는다.
2. 그다음 음식마다 **프롬프트 한 줄**을 보내 그림을 받는다. (한 번에 여러 개를 부탁하면 품질이 떨어지므로 한 메시지에 1~2개가 좋다.)
3. 받은 그림은 **파일 이름을 id로**(예 `f55.png` 또는 `f55.jpg`) 바꿔 한 폴더에 모은다. 크기는 1024×1024면 충분하다(우리가 600px JPEG로 줄인다).
4. 폴더를 알려 주면 변환 → `apps/web/public/food-img/` → DB `foods.image_url` 연결 → 번들 내보내기까지 처리한다(기존 24장과 같은 길, 출처 "AI 생성 이미지 · 페어링GO").

### 공통 지시 (처음에 한 번)

```
지금부터 한국 술 페어링 앱에 쓸 안주 사진을 만들어 줘. 아래 규칙을 모든 그림에 똑같이 적용해.

- 정사각형(1:1), 사진처럼 사실적인 음식 사진. 일러스트·그림체 금지.
- 구도: 위에서 약 45도로 내려다본 각도, 음식이 화면 가운데에 크게(화면의 70% 이상).
- 배경: 어두운 원목 식탁 또는 짙은 회색 돌판, 배경은 살짝 흐리게. 소품은 작은 접시·젓가락 정도만, 술병·술잔은 넣지 마.
- 조명: 따뜻한 자연광, 음식 표면의 윤기와 김이 살아 있게.
- 그릇: 한식은 유약 바른 도자기·놋그릇·무쇠 팬, 양식·일식·중식은 그 나라에 맞는 그릇.
- 글자·로고·워터마크·사람·손 넣지 마.
- 음식은 실제 한국 식당·가정에서 나오는 모양 그대로 (양·썰기·고명 포함). 과장하거나 낯선 재료를 더하지 마.

내가 음식 이름과 설명을 한 줄씩 보낼 테니 그때마다 그림 한 장을 만들어 줘.
```

## 3. 받은 뒤 처리 (운영자 메모)

- 폴더의 `fNN.png|jpg` → `scratchpad imgtool/convert.mjs`와 같은 방식으로 600px JPEG 82 → `apps/web/public/food-img/fNN.jpg`
- DB: `update foods set image_url='/food-img/fNN.jpg', image_credit='AI 생성 이미지 · 페어링GO'` + `catalog_meta.version` 올림 → `pnpm --filter @pairinggo/db export` → 커밋·푸시
- 사실과 다른 그림(낯선 재료·엉뚱한 모양)은 넣지 않고 다시 만든다. 그림은 실제 음식 사진이 아니라는 뜻으로 출처를 "AI 생성 이미지"로 밝힌다.
