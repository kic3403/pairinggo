## 1. 만든 것

| 영역 | 내용 |
|---|---|
| 구조 | pnpm 워크스페이스 — `apps/miniapp`(Vite 8 + React 19 + Tailwind 4 + react-router 7, 앱인토스 SDK 3.4) · `packages/shared`(데이터·로직, Vitest) |

| 상황 검색 (`search/intent.ts`) | 연결어("~에 어울리는")로 주어/대상 분리, 맛 12규칙·도수·종류·음식 분류·지역·수상·선물 → 조건에 맞는 주어들의 페어링을 집계해 순위. 해석 불가·종류/지역 단어 하나는 일반 검색 폴백 |
| 종합 탭 (`pairing/score.ts`) | 전문가 60% + 대중 언급(log) 25% + 맛 프로필 15% + 출처 등급 보너스, 상위 5 편중 보정 −5. 카드에 기여도 표시 |
| 홈 | 검색 → 상황 예시 칩 → **종류별 탐색 8칩** → 지역 술 → 오늘의 페어링 → 대통령상 → 인기 검색어 → 최근 검색 |
| 둘러보기 `/browse/:kind/:key` | 종류·지역·양조장·음식 분류 목록, 정렬 5종, 도수 구간·맛 태그 필터 |
| 술 상세 | **5축 레이더**, 유사 술(맛 프로필 거리 반영), 직판 확인 카드(주소·길찾기·전화), 온라인 판매 불가 7종 배지·안내, 구매 버튼 "양조장 공식몰로 이동" |
| 공통 | 외부 링크는 `openExternal`(SDK `Device.openURL`)로만, 퍼널 이벤트 로컬 큐 + `Analytics.log`, 주류 경고·만 19세 고지 푸터, 라이트·다크 토큰 |
| 식당 찾기 | Phase 1 축소판(관심지역 + 네이버지도 링크). 앱 내 별점 리스트는 Phase 3 |

## 3. 사용자가 할 일 (콘솔)
1. 앱인토스 콘솔 가입 → 워크스페이스 → 미니앱 등록 (appName **pairinggo**, 카테고리 추천·정보, 아이콘 `apps/miniapp/public/icons/icon-512.png`)
2. `pnpm --filter miniapp build` 후 `apps/miniapp/pairinggo.ait`를 콘솔에 업로드(또는 `npx ait deploy`) → 토스앱 테스트 QR로 실기기 확인
3. 위 "못 한 검증" 3가지 확인 후 결과 공유 → 문제 있으면 Phase 1 보정 후 Phase 2 진행
4. 병행: 사업자등록, 정산대행·토스페이 전통주 확인 (docs/06 1번 표)

## 4. 계획 대비 변경
- 앱인토스 SDK가 3.x로 바뀌어 `granite.config.ts` → `apps-in-toss.config.ts`, 샌드박스 앱 → AIT Devtools(브라우저)로 테스트 방식이 바뀜
- React 18 대신 **React 19** 사용 (web-framework에 peer 제약 없음, TDS 미사용)
- Sentry는 Phase 3로 미룸
