# 술 사진 요청 절차 (2026-09-12)

홈 배너·목록 카드가 병 실루엣인 이유: 더술닷컴(aT)·네이버·블로그 사진은 저작권(공공누리 4유형 = 상업적 이용 금지) 때문에 쓸 수 없다.
**양조장이 직접 제공하고 사용을 허락한 사진만** 넣는다. 허락 회신(메일)은 보관한다.

## 1. 명단 만들기
```bash
pnpm --filter @pairinggo/db photo-request --top 30     # → packages/db/templates/사진요청_상위30.xlsx
```
순위는 최근 export된 인기 순위(`trend.rank`). 양조장 주소·홈페이지·전화는 더술닷컴 자료에서 자동으로 채워지고, 이메일은 홈페이지·전화로 확인해 적는다.
(하이트진로·보해양조·경주법주·수왕사는 자료에 없어 직접 찾는다. 대기업 3곳은 홍보팀 메일이 있다.)

## 2. 메일 문안 (복사해 쓰기)

제목: [페어링GO] {술 이름} 제품 사진 사용 허락 요청

> 안녕하세요, 전통주·음식 페어링 서비스 페어링GO(https://pairinggo.vercel.app)를 운영하는 {이름}입니다.
> 저희 서비스는 전통주를 고르면 어울리는 안주를, 안주를 고르면 어울리는 전통주를 양조장·소믈리에·매체의 근거와 함께 보여 드리고, 구매는 각 양조장 공식몰로 연결합니다(직접 판매하지 않습니다).
>
> 현재 {술 이름}이(가) 저희 "요즘 많이 찾는 전통주" {순위}위에 올라 있어 홈 첫 화면과 목록에 제품 사진을 싣고자 합니다. 아래 조건으로 사진 사용을 허락해 주실 수 있을까요?
>
> - 용도: 페어링GO 웹사이트·앱의 제품 소개(홈 배너, 목록, 상세 화면)
> - 표기: 사진마다 "{양조장명} 제공"을 표시합니다
> - 변경: 크기 조정·잘라내기 외에는 수정하지 않습니다
> - 기간: 사용 중단 요청을 주시면 즉시 내립니다
> - 사진: 병 정면 1장(배경 단색, 가로 800px 이상)이면 충분합니다. 공식몰 사진을 그대로 써도 된다고 해 주시면 그 주소를 알려 주십시오.
>
> 답신은 이 메일로 부탁드립니다. 감사합니다.
> {이름} / 페어링GO / {전화} / {사업자등록번호}

전화로 먼저 물으면 회신율이 높다. 통화 뒤 "방금 통화한 내용대로" 메일을 보내 기록을 남긴다.

## 3. 받은 사진 넣기
1. 사진을 우리 저장소(Supabase Storage 버킷 `pairinggo-images`, 공개 읽기)에 올린다. 파일명은 술 id(`d01.jpg`). 양조장 사이트 주소를 직접 걸지 않는다(그쪽이 바꾸면 깨진다).
2. 엑셀의 **술 · 받은 사진 주소 · 출처표기 · 허락 근거** 네 열을 CSV로 저장한다.
3. 넣는다:
```bash
pnpm --filter @pairinggo/db images 사진.csv --dry     # 확인만
pnpm --filter @pairinggo/db images 사진.csv           # 저장
```
4. 5분 안에(카탈로그 캐시) 홈 배너 타일이 사진으로 바뀐다. 미니앱은 다음 어드민 발행 때.

스크립트는 더술닷컴 주소(thesool.com)·jpg/png/webp가 아닌 주소·출처표기 없는 행을 거른다.

## 4. 원칙
- 허락 없는 사진은 넣지 않는다. "홈페이지에 공개돼 있으니까"는 허락이 아니다.
- 사진마다 `image_credit`("○○ 제공")이 화면에 붙는다. 비워 두면 스크립트가 거른다.
- 양조장이 사용 중단을 요청하면 `image_url`을 비운다(`update drinks set image_url=null, image_credit=null where id=…`).
- 상위 30종부터, 회신 오는 대로 넣는다. 다음 순위는 매달 순위가 바뀐 뒤 다시 명단을 뽑는다.
