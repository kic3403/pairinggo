# 19. 데일리샷·캐치테이블 분석과 페어링GO 적용안 (2026-09-14)

두 서비스는 페어링GO의 3단계 목표(추천 → 전통주 구매 중개 → 식당 예약)에서 각각 2단계·3단계의 기준점이다. 공개 자료(공식 사이트, 2026년 보도, 이용 후기)로 기능을 확인하고, 우리 규모(회원 수 명, 술 217종·식당 DB 없음)에서 바로 쓸 것과 나중에 쓸 것을 나눴다.

## 1. 데일리샷 — 주류 스마트오더 1위

### 1-1. 사실 (2026년 기준)
| 항목 | 내용 |
|---|---|
| 규모 | 누적 앱 설치 281만(2026-03), "국내 1위 온라인 주류 오더 플랫폼". 2026 넥스트라이즈에 CJ 그룹 부스로 참여 |
| 핵심 구조 | **앱에서 사고 가까운 곳에서 받는다** — 주류통신판매 규제(온라인 배송은 전통주만 가능) 안에서 스마트오더로 우회 |
| 받는 곳 | 파트너 픽업(식당·바 3,653곳) · 스토어 픽업(주류점 826곳) · CU 오늘픽업(11,655점)·예약픽업(15,651점) · 이마트24 오늘·예약픽업(2026-03 입점, 약 2,000점) · 택배(전통주 등 1,459종) · 해외직구 · 신라면세점 픽업 |
| 정보 | 종류·용량·도수·나라·품종·역사, **전국 가격 비교**, 지도에서 판매처 찾기, 실구매 리뷰 |
| 유입·보상 | 추천인 코드 3,000~5,000P, 신규 첫 구매 할인, 편의점 전용 쿠폰, 블로그 체험단(제품 구입비 지원 표기) |
| 운영 디테일 | 주문 확정·픽업 기한을 카카오톡 알림으로, 기한 넘기면 매장 요청으로 취소 |

### 1-2. 왜 되는가
1. **구매 마찰을 없앴다** — "어디서 파는지·얼마인지·재고가 있는지"를 앱이 답하고, 결제는 앱에서 끝난다. 사용자는 가게에 가서 이름만 대면 된다.
2. **판매처 망이 곧 해자** — 편의점 2만 점 + 주류점·식당 4천 곳. 같은 술을 더 가까운 곳에서 더 싸게.
3. **리뷰가 구매에 붙어 있다** — 실구매자만 쓰는 후기라 신뢰가 높고, 리뷰 체험단으로 콘텐츠를 늘린다.
4. 전통주는 **택배가 되는 유일한 주종**이라 데일리샷 안에서도 별도 카테고리·택배 채널로 다룬다.

### 1-3. 우리와의 차이
- 데일리샷은 "무엇을 살지 정한 사람"을 위한 앱. 페어링GO는 "무엇을 마실지 아직 모르는 사람"(음식이 먼저)을 위한 앱. **탐색 단계에서 우리가 앞에 서고, 구매는 데일리샷·양조장 몰로 넘겨도 된다.**
- 데일리샷에는 페어링 근거·전문가 인용·먹어봤어요 같은 "왜 이 술인가"가 없다.

## 2. 캐치테이블 — 식당 예약·웨이팅 1위

### 2-1. 사실 (2026년 기준)
| 항목 | 내용 |
|---|---|
| 규모 | 누적 가입자 1,500만(국내+글로벌, 2026-09), 입점 매장 3만, 글로벌 앱 MAU 112만(2026-05). 2018 B2B 예약 솔루션 → 2020 소비자 앱 → 2023-06 실시간 웨이팅 → 결제·픽업 |
| 재방문 | 매장 재방문율 2.4배(2022-01 → 2026-08), 연 24회 이상 예약 고객 6.5배, 1인당 예약 2.35회·웨이팅 2.66회 |
| 범위 | 1인 2만 원 이하 동네 맛집 ~ 20만 원 이상 파인다이닝, 14개 음식 카테고리(한식·양식·일식·중식·오마카세·코스…), 비수도권 웨이팅 5.8배 성장(전북) |
| 기능 | 실시간 예약(빈 시간대 보기), 원격 줄서기·**미루기**·순서 알림, **예약금·노쇼 제재**(취소 규정, 계정 제한), 예약 오픈 알림(푸시·문자), 선호 지역·음식 설정, 결제, 픽업, 관리자 앱·POS |
| 콘텐츠 | **트렌드 리포트**(예: 방어 검색량 9월 급증), 인기 급상승 식당 순위, 다이닝 매거진(미쉐린 스타 식당), 흑백요리사 시즌2 공식 파트너(출연 셰프 식당 모아 보기), 호텔 뷔페 페스타(70여 호텔), 브랜드 협업 프로모션(콜키지 프리·와인잔 증정·시음 쿠폰) |

### 2-2. 왜 되는가
1. **매장 쪽 도구가 먼저** — 예약·웨이팅 관리 솔루션을 매장에 깔고, 그 재고(빈 자리)를 소비자 앱에 연결. 공급이 실시간이라 소비자 앱이 신뢰를 얻는다.
2. **"지금 갈 수 있나"를 답한다** — 웨이팅 미루기·알림 같은 작은 기능이 재방문을 만든다(2.4배).
3. **자기 데이터로 콘텐츠를 만든다** — 검색량·예약 데이터로 트렌드 리포트와 급상승 순위를 내고, 방송·브랜드와 묶어 유입을 만든다.
4. **노쇼를 규칙으로 막는다** — 예약금과 제재가 매장 신뢰를 지킨다.

### 2-3. 우리와의 차이
- 캐치테이블은 식당 예약이 목적이고 술은 프로모션(콜키지) 수준. 우리는 "이 음식엔 이 전통주"에서 출발해 식당으로 가는 반대 방향.
- 캐치테이블에는 이미 미쉐린·급상승·매거진이 있다. 우리가 같은 것을 만들면 지고, **술과 음식의 짝**이라는 축으로 식당을 고르게 해야 한다.

## 3. 페어링GO에 적용할 것 (우선순위)

기준: 지금 자산(근거 있는 페어링 1,790조합, 회원 평가·추천, 미쉐린 배지, 관심지역, 우리술품평회)으로 바로 만들 수 있고, 유입·재방문·구매 전환 중 하나에 직접 닿는 것.

## 3-1. 적용 기록
- **A3 급상승 (2026-09-14 완료)** — 크론이 오늘 순위와 함께 "7일 전을 오늘로 둔" 순위를 같은 규칙으로 한 번 더 계산해 `drinks.trend.prev_rank/delta`에 붙인다(`attachRankDelta`). 홈 배너 타일과 리포트에 ▲N·▼N·–·NEW 배지(`deltaBadge`). 비교 기준(`trend_meta.compared_to`)이 없으면 배지를 숨긴다 — 일주일 치 기록이 쌓인 뒤 자동으로 나타난다. 배포에서는 Vercel 환경변수(네이버·유튜브·구글 키) 등록이 선행.
- **A2 월간 트렌드 리포트 (2026-09-14 완료)** — `/report`(1시간 캐시, `lib/report.ts`): 최근 30일 기준 많이 찾는 전통주 TOP 10(+▲▼), 핫한 페어링, 먹어봤어요(3명 이상), 회원 추천 공개 조합, 검색어 TOP 10, 지역별 둘러보기, 활동 수(회원·화면·검색·구매/식당 링크·저장·평가). 홈 배너 아래 "N월 트렌드 리포트" 카드. "글로 복사" 버튼이 블로그·인스타용 평문(`reportText`)을 만든다 — 매달 1일 복사해 올리면 된다. 언급량은 게시물 수이지 판매량이 아니라는 문구 포함.
- **A1 추천인 (2026-09-15 완료)** — 가입(이메일)과 가입 마무리(간편가입 /profile)에 "추천인 닉네임(선택)" 칸. `users.referred_by/referred_at`(0019), 없는 닉네임이면 안내하고 멈춤(오타 확인), 본인 불가, 가입 뒤엔 바꾸지 않음. 마이페이지 "초대한 친구 N명". 포인트·현금성 보상 없음.
- **A6 대신 먼저 — 먹어봤나요? 카드 (2026-09-15 완료, docs/20 P1-1)** — 마이페이지 상단에 저장한 술·음식으로 고른 미평가 조합 3개(`suggestTried`, 상세와 같은 정렬)를 그 자리에서 평가. 평가한 조합은 다음부터 빠진다.

## 4. 제안하는 순서
1. A3 급상승 화살표 + A2 월간 트렌드 리포트(같은 데이터) — 유입 글감이 생긴다.
2. A1 추천인 코드 — 지인 배포 확산.
3. A6 실구매·실방문 표시 + A5 파는 곳 표 정리 — 신뢰·전환.
4. A4 취향 설정 — 회원이 수십 명 넘으면.
5. B·C는 신고·계약 진행에 맞춰.

## 5. 화면 구성(레이아웃) 비교와 적용 (2026-09-14)

사용자 요청: "데일리샷·캐치테이블을 상세 분석해 우리 앱 레이아웃에 적용할 것이 있는지 — 확인 없이 결과까지". §1~3이 기능 비교였다면 여기는 화면 구성. 두 서비스의 웹 화면을 크롬으로 직접 열어 확인했다(데일리샷 dailyshot.co 홈·우리술 TOP10·상품 상세, 캐치테이블 app.catchtable.co.kr 홈). 캐치테이블 검색·식당 상세는 웹에서 빈 화면이라 확인하지 못했다.

### 5-1. 확인한 화면 구성
| 요소 | 데일리샷 | 캐치테이블 | 페어링GO(적용 전) |

### 5-3. 적용하지 않은 것과 이유
- **배너 캐러셀·앱 설치 팝업**: 알릴 이벤트·앱이 아직 없다. 첫 화면을 가리는 팝업은 이탈을 늘린다.
- **가격·할인율·"구매 2,200+" 같은 판매 수치**: 우리는 판매자가 아니고 가격 데이터 계약이 없다(§3 D). 판매 수치 대신 쓸 수 있는 신뢰 표시는 먹어봤어요·회원 추천·하트 수 — 회원이 늘면 상세 상단에 "먹어봤어요 N명 · 어울렸다 N%" 줄로(§3 A6와 함께).
- **순위 배지 목록(TOP10)**: 전통주·음식 목록은 가나다순이 사용자 결정. 순위는 홈 "요즘 많이 찾는 전통주 10"과 리포트에 이미 있다.
- **상단 두 번째 탭 줄(캐치단독·혜택·피드)**: 나눌 만큼 콘텐츠 종류가 없다. 아이콘 메뉴(QuickMenu)가 그 역할.
- **사진 중심 카드**: 술 사진은 허락받은 것만 쓴다는 규칙(photo-request) — 사진이 모이면 카드 상단에 붙인다.
